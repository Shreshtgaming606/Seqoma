# Experimental SpreadPaper Sonoma port

These files document an isolated, ad-hoc-signed source port of [SpreadPaper v1.10.1](https://github.com/spreadpaper/SpreadPaper/releases/tag/v1.10.1) for x86_64 macOS 14. The test app archive is not distributed with the Seqoma beta. The original release and the tester's desktop were not modified.

On an Intel MacBook Air running Sonoma 14.8.9, the port passed structural, architecture, dependency, and signature checks. It launched and displayed the welcome screen, Continue/Back navigation, an image picker, and its icons. **Image import, wallpaper application, previews, scheduling, and settings are unverified.** The app is an experimental build, not a fully validated replacement for the official release.

This port was compiled and assembled manually, then analyzed and launched through Seqoma's CLI. Seqoma's current `swiftc` source recipe cannot perform this multi-target Xcode build. See [TEST_REPORT.md](../TEST_REPORT.md) for hashes and results.

## Reproduction files

- `SpreadPaper-source.patch`: changes against SpreadPaper tag `v1.10.1` needed for the older Swift toolchain and macOS 14 SDK.
- `SpreadPaper-project-sonoma.yml`: isolated XcodeGen project, excluding the app's large image asset catalog from compilation.
- `SpreadPaper-GeneratedAssetSymbols.swift`: asset names generated by Xcode's asset tool and retained for the source compile.
- `SpreadPaper-Package.resolved`: pins PhosphorSwift to revision `9a9467181782bbe319ad4935d0993c77cd8a5fbc`, version 2.1.0.
- `PhosphorSwift-source.patch`: excludes its large asset catalog from the code build and loads its already compiled icons from the official release's bundled resources.

To reproduce, clone SpreadPaper at tag `v1.10.1`, apply `SpreadPaper-source.patch`, copy the YAML and generated symbols into the positions shown by the YAML, and generate `SpreadPaperSonoma.xcodeproj` with XcodeGen 2.46. Copy `SpreadPaper-Package.resolved` to `SpreadPaperSonoma.xcodeproj/project.xcworkspace/xcshareddata/swiftpm/Package.resolved`. Xcode 15.4 requires changing the generated project's `objectVersion = 77` and `preferredProjectObjectVersion = 77` entries to `60`.

Resolve packages in Xcode 15.4. In the resulting `DerivedData/SourcePackages/checkouts/swift` checkout, apply `PhosphorSwift-source.patch` after making its `Package.swift` and `Sources/PhosphorSwift/PhosphorSwift.swift` writable. Build the `SpreadPaperSonoma` scheme for x86_64 with `MACOSX_DEPLOYMENT_TARGET=14.0` and signing disabled. Copy its main executable into a **separate copy** of the official SpreadPaper 1.10.1 app, preserve the release's resources, set the copied `Info.plist` `LSMinimumSystemVersion` to `14.0`, and sign that copy ad hoc. Run Seqoma's analyzer and launch test before using it further. These reproduction steps need the official release and source.
